# ADR 0004: Datos sintéticos y simulación explícita

- Estado: Aceptado.
- Contexto: No hay clientes ni dispositivos GPS reales para poblar el producto.
- Decisión: generar una empresa ficticia y datos sintéticos reproducibles. Revisión 2026-11-09, por decisión del propietario: la consola se presenta como una operación real y no muestra avisos de simulación; el README y esta documentación declaran que datos, posiciones y eventos son sintéticos.
- Consecuencias: demo siempre poblada y repetible, y quien consulte el repositorio sabe que no hay integraciones reales.
