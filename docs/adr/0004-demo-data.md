# ADR 0004: Datos sintéticos y simulación explícita

- Estado: Aceptado.
- Contexto: No hay clientes ni dispositivos GPS reales para poblar el producto.
- Decisión: generar una empresa ficticia y datos sintéticos reproducibles; declarar en la UI que posiciones y eventos son simulados.
- Consecuencias: demo siempre poblada y repetible, sin engañar sobre integraciones reales.
