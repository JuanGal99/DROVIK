# 1. Visión del producto

## 1.1 Problema

Una empresa logística necesita conocer el estado de sus envíos y recursos operativos, coordinar vehículos y conductores, anticipar incidencias y comprender el rendimiento de sus operaciones. DROVIK presenta un entorno demostrativo para explorar esos flujos desde una consola central.

## 1.2 Producto

DROVIK es una plataforma web de inteligencia logística para una empresa ficticia. Reúne administración de flota, gestión de envíos, asignaciones, mapa operativo, simulación de recorridos, incidentes y métricas.

## 1.3 Usuarios

- **Administrator:** administra usuarios, catálogos y configuración de la demo; tiene acceso completo.
- **Operator:** consulta la operación diaria, gestiona envíos y asignaciones, ejecuta escenarios permitidos y atiende incidentes.

Los conductores son registros operativos, no cuentas de acceso.

## 1.4 Alcance de demostración

- Una sola empresa ficticia.
- Datos sintéticos, coherentes y reproducibles.
- Aplicación pública con acceso de demostración controlado.
- Recorridos simulados; sin GPS real.
- Rutas precalculadas o geometrías de respaldo para evitar depender de servicios externos durante la demo.

## 1.5 Criterios de éxito

- Un visitante puede comprender el producto en pocos minutos.
- Los flujos principales pueden demostrarse sin crear datos manualmente.
- El mapa refleja posiciones simuladas en tiempo real.
- Las incidencias afectan de forma visible el estado operativo.
- Los servicios se pueden ejecutar localmente con instrucciones reproducibles.
- Las decisiones de arquitectura pueden explicarse y probarse.
